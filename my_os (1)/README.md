Учебный
 проект по дисциплине «Осуществление интеграции программных
модулей». Представляет собой симулятор операционной системы, реализованный
на Python с использованием SQLite.
- Управление пользователями: регистрация, вход, роли, разграничение прав.
- Иерархическая файловая система: каталоги, файлы, дерево, копирование,
перемещение.
- Управление процессами: создание, планирование, завершение.
- Управление памятью: выделение, освобождение, контроль лимита.
- Журналирование системных вызовов.
- Командная оболочка с двадцатью и более командами.
Стек технологий
- Python 3.10+
- SQLite (встроенная в Python)
- VS Code
- Git
