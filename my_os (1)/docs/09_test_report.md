# Итоговый протокол тестирования

## 1. Тестируемая система
Учебная операционная система **StudyOS**. Реализована на **Python 3.10** с использованием **SQLite**. 

Система состоит из следующих архитектурных модулей:
* `db.py` — подсистема работы с базой данных
* `kernel.py` — ядро операционной системы
* `auth.py` — модуль аутентификации и авторизации пользователей
* `fs.py` — виртуальная файловая система
* `scheduler.py` — планировщик и диспетчер процессов
* `syscalls.py` — интерфейс системных вызовов
* `shell.py` — командный интерпретатор (оболочка пользователя)

## 2. Объём тестирования
В ходе верификации операционной системы были проведены следующие виды тестирования:

* **Функциональное тестирование:** проверка бизнес-логики модулей `fs.py`, `scheduler.py`, `syscalls.py`.
* **Интеграционное тестирование:** сквозная проверка взаимодействия компонентов в связках:

* **Системное тестирование:** выполнение четырех комплексных сквозных сценариев (`SS-01` – `SS-04`).
