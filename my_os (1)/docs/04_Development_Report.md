# Отчёт по дню 4

## Что сделано
- **Расширен db.py**: добавлены функции `execute_insert`, `execute_select`, `execute_update`, `execute_delete` для безопасной и централизованной работы с БД.

- **Обновлён syscalls.py**: интерфейсные функции `sys_login`, `sys_whoami`, `sys_delete_file`, `sys_kill` переведены со старых заглушек на использование реальной логики ядра и модулей безопасности.

- **Написаны тесты** `test_kernel.py` и `test_auth.py` для автоматической верификации модулей.
