# Системные сценарии
## SS-01: Первый запуск ОС
**Предусловие:** файл db/os.sqlite отсутствует, все модули src гот1. Удалить файл db/os.sqlite.
2. Запустить python src/db.py.
3. Убедиться, что файл создан.
4. Открыть его через SQLite Viewer.
5. Проверить наличие таблиц: users, processes, files, syscalls_log,
memory_state, roles.
6. Проверить, что таблица roles содержит три записи: admin, user, guest.
**Ожидаемый результат:** база создана, все таблицы присутствуют, роли
заполнены.
**Постусловие:** система готова к первому запуску.

## SS-02: Работа администратора
**Предусловие:** пользователь admin зарегистрирован с ролью admin, пароль
admin123.
**Шаги:**
1. Запустить python -m src.shell.
2. Войти как admin.
3. Создать файл /ss02_a.txt с содержимым "first file".
4. Создать файл /ss02_b.txt с содержимым "second file".
5. Прочитать файл /ss02_a.txt.
6. Запустить процесс app1.
7. Запустить процесс app2.
8. Вывести список процессов.
9. Завершить процесс app1.
10. Проверить состояние памяти.
11. Выйти.
**Ожидаемый результат:** все команды выполнены, файлы созданы, процессы
запущены и завершены, память освобождена, журнал заполнен.

## SS-03: Работа обычного пользователя
**Предусловие:** пользователь user зарегистрирован с ролью user, пароль
user1234. Файл /ss02_a.txt принадлежит admin.
**Шаги:**
1. Запустить python -m src.shell.
2. Войти как user.
3. Создать свой файл /ss03_my.txt.
4. Попробовать удалить файл /ss02_a.txt, принадлежащий admin.
5. Запустить свой процесс user_app.
6. Попробовать завершить процесс admin.
7. Выйти.
**Ожидаемый результат:** свои действия разрешены, чужие запрещены, отказы в
журнале со статусом DENIED.

## SS-04: Восстановление после ошибок
**Предусловие:** система работает, пользователь admin зарегистрирован.
**Шаги:**
1. Запустить оболочку.
2. Попробовать войти с неверным паролем.
3. Войти с правильным паролем.
4. Попробовать прочитать несуществующий файл.
5. Попробовать завершить несуществующий процесс.
6. Попробовать создать дубликат файла.
7. Убедиться, что система продолжает работать.
8. Выйти.
**Ожидаемый результат:** система обрабатывает ошибки без падения, выводит
корректные сообщения, продолжает принимать команды.
